---
description: 同步中英文档的变更，并在修改后翻译
---

如果项目的中文版文档（如 `README_CN.md` 和 `DEVELOPMENT_CN.md`）有任何变更，请遵循以下流程同步更新相应的英文文档（如 `README.md` 和 `DEVELOPMENT.md`）：

1. **分析变化**：找出此次中文版文档中的新增、修改或删除内容。
2. **寻找对应**：在当前的英文版文档中定位需要同步更新的对应段落或具体位置。
3. **结合语境翻译**：将中文增量或变更内容翻译成英文。**请务必确保翻译符合英文技术写作习惯（例如：技术名词和缩写要准确，行文连贯），避免生硬的机器直白翻译**。
4. **验证结构**：检查中英文两边的 Markdown 排版是否有因为同步导致不一致的情况。
