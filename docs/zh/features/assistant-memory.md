# 长期记忆

在 Web 和 Tauri 打开 **AI助手 → 会话 → 个人对话**。在 Android 的设备列表菜单或 iOS 的设备列表中，选择**个人对话**。你可以在未选择设备时与助手对话。开启自动记忆后，助手可保存和检索你的个人记忆。打开“历史”可继续、新建或删除个人对话。

Web 和 Tauri 再次打开助手时，会恢复当前浏览器上次选择的会话。恢复失败时，页面提供“重试”和“新对话”；恢复成功或明确新建后可继续发送。新建对话保留原有存储数据。

旧格式会话仍显示在历史列表中，标记为“无法继续对话”，可直接确认删除；它们也按原会话闲置保留期自动清理。真实在途操作、未知结果和待结算用量继续按原规则保留相关证据。

会话列表以简短标题标识对话。首次交流时，助手使用当前模型根据首问自动命名，生成前或未生成成功时显示首问的短摘要。标题生成的用量计入正常模型用量。

## 个性化

Web 和 Tauri 在聊天页点击“+ → 管理 → 个性化”，也可从 AI 助手总览打开；Android 从设备列表菜单打开，iOS 从设备列表打开。

填写希望所有新对话遵循的要求，例如默认语言、回答顺序和详细程度。内容容量默认 8 KiB，以当前服务配置为准。保存后用于新对话，已有对话继续使用开始时的设置。定时任务使用定义任务时保存的个性化。

同页可分别设置“自动记忆”“跨会话搜索”。两个开关分别保存：关闭自动记忆后仍可查看和删除已有记忆；跨会话搜索也可独立开启。设置在其他位置被修改时，页面保留草稿并提示重新加载；重新加载会替换尚未保存的修改。

## 查看和删除长期记忆

长期记忆用于个人 AI 助手，按账号保存，可跨设备、跨模型使用。助手会在正常对话中整理稳定事实，也可根据你明确提出的保存、纠正或遗忘要求处理记忆。日常使用只需向助手说明；管理页用于查看和删除。

你可以直接问“我之前让你怎么称呼我”。助手平时使用当前记忆，回答历史问题时可查询仍可访问的留存版本。版本记录时间表示平台保存该版本的时间；事实实际发生时间可继续查看来源。遗忘也会停止对旧版本的新读取。

Web 从 AI 助手总览打开“长期记忆”；Android 从设备列表菜单打开，iOS 从设备列表打开。页面可筛选个人或设备范围，查看正文、背景、版本、记录时间、更新时间及可用来源。

- **删除一条**：点击“删除记忆”并确认。条目已更新时，先查看最新版本再确认。
- **清空全部**：单独确认后删除本人全部个人和设备记忆，包括当前筛选外的条目。
- **纠正内容**：在对话中说明正确事实，助手根据来源处理更新。

删除后，助手停止将该事实作为当前记忆使用，并阻止从其已知旧依据重新学习。原聊天和个性化仍保留；需要移除原文时，删除对应会话。若几条事实来自同一个不可分离的原文片段，删除其中一条也可能影响其他事实对该片段的读取。

删除结果以服务端确认和管理页为准；网络结果不明确时可重试。助手在工具返回后继续反馈处理结果，回复失败也保留已经提交的删除。

### 查看来源

点击回答中的来源、记忆的“查看原会话”或历史搜索结果，会进入 AI 助手聊天页的只读历史模式，定位并高亮原消息；可继续查看附近、较早和最新内容。来源设备离线也可查看仍被保留的历史，当前聊天的草稿和任务保持原状。

“查看会话最新内容”加载最新一页并滚动到末尾；“定位原文”回到引用位置；“加载更早消息”向更早的时间分页。消息按从早到晚的顺序展示。

原聊天已自然到期时，记忆若有独立有效的依据，可显示为“留存依据”；它与完整原聊天分别保留。手工删除会话会停止提供该会话及其子会话的来源，并停止使用依赖它们的记忆。来源被删除、到期或失去访问资格时，页面显示不可用。遗忘记忆后，本人仍可查看合法保留的原聊天。

可点击来源以平台实际核对的记录为准。每条回答的引用数量默认最多 64 条，引用元数据默认最多 8 KiB，两项均可配置；展示不完整时会提示。来源链接按其当前权限、版本和有效期打开。

### 已保存的聊天内容

检索结果成功保存到当前会话后，作为读取当时的独立快照保留。原会话后来删除、到期或更新，当前会话已保存的片段、回答和摘要仍可使用；删除当前会话会删除它管理的内容。当前记忆在每轮请求时刷新，已有聊天回答保留当时内容。

新检索和原来源链接按来源当前状态处理，内容的复制、导出限制及硬性到期要求仍适用。历史记录说明当时发生了什么；再次执行操作需要当前权限和目标状态。

### 保存过程与费用

对话模型根据当前输入和已有记忆整理正文、背景，并决定新增或更新。平台检查来源权限、版本与容量后立即保存，工具返回提交结果后，助手继续反馈。更新保留可查询的历史版本；版本冲突时，助手重新查询后再处理。

记忆保存使用正常对话的模型调用与额度。自配模型的费用以供应方记录为准。

## 临时对话

在个人 AI 助手的会话列表选择“新建临时对话”。临时对话使用个性化要求，但不读写长期记忆、不搜索其他会话，也不进入跨会话搜索。普通聊天记录、必要审计和任务恢复数据按原规则保留；需要移除记录时仍应删除会话。

模式在首条输入被接收时固定，刷新、重连和重试沿用该模式。切换模式时新建对应类型的对话。

## 搜索其他会话

开启“跨会话搜索”后，可直接询问“帮我找一下之前对某个主题的调研”或“我上周给谁发过文件”。助手搜索当前部署中本人账号仍可读取的留存记录，包括其他设备的会话，并按需读取附近原文。同一轮搜索仍受获准的设备、时间和内容范围约束。

搜索覆盖用户输入、助手回复和获准留存的工具记录，使用关键词和时间范围，长消息的尾部也可命中。结果先显示片段预览，再按需读取原文。未命中或范围不完整，只能说明当前可用记录未找到证据；历史陈述本身也不能证明任务已经完成。

### 相对时间

“昨天、上周”等相对时间按发送这条消息的客户端系统时区解释。Web/Tauri、Android 和 iOS 每次发送都携带客户端时区；重试保留原时区。消息接收时间表示平台接纳输入的时刻，事情发生的时间仍依据原文和证据确定。定时任务使用各自设置的时区。

### 长期目标与定时任务

已有目标和定时任务使用创建时获准的记忆与历史范围；后来开启开关时，需要创建新任务来使用新增能力。关闭开关会限制后续读取。长期任务中新发送的本人消息按发送时的自动记忆设置处理，关闭期间的旧输入保持原状。

定时任务需求与运行结果只有在资料允许留存时才进入搜索。手工填写的任务需求不会自动成为长期事实；由 AI 整理的需求继承来源限制。每次运行保留当时的需求，后来编辑任务也保留旧实例的内容。

## 本人历史搜索与管理

打开 AI 助手的“历史搜索”，按关键词和时间范围查看本账号各设备仍保留的内容；留空关键词可按时间浏览。本人查看历史独立于模型的“跨会话搜索”开关，来源设备离线也可使用。结果达到候选、时间或容量预算时会说明范围不完整。

“留存的对话”按主会话列出，执行状态已回收的对话以只读方式展示。确认删除会话后，仍在运行的工作停止，关联历史和依赖记忆撤销，必要的对账和设备文件清理记录按原规则保留。已经发出的邮件等外部操作仍然有效。

## 数据处理状态与技术重试

“数据处理状态”展示历史收录覆盖、缺口和存储计数，可按页面原因检查收录情况。

存储计数可能包含等待清理的记录。查询缺口或容量不足时，应结合页面返回的原因判断结果；已发布记忆以长期记忆管理页为准。
