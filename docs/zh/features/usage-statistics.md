# 用量统计与数据保留

便携版 / 信令服务器把 **TURN 中继流量**（按设备）与 **AI 网关 token 用量**（按模型）记入本地 SQLite 的**逐小时汇总**。这是用于容量与成本观测的**纯采集遥测**——单机服务器不做计费。

## 用量页面与查询范围

**用量**区提供两个视图——**TURN 流量**（按设备）与 **AI Token 用量**（按模型），每页顶部都带**时间范围选择器**：

- **预设**：最近 24 小时 / 最近 7 天 / 最近 30 天，或选**自定义**起止时间。
- **实际范围**：后端会把请求范围收敛到配置的保留期与「现在」之内，并在图表下方回显实际查询到的范围。
- **按天聚合（UTC）**：跨度超过 **14 天**时自动按 **UTC 自然日**聚合以控制查询开销；日界固定以 UTC-0 为准，与本地时区无关。
- **与 TURN 是否在运行无关**：两个视图读的都是已落库的汇总，因此 TURN 未配置、启动失败或被关闭时，历史流量照样查得到。凡是有本地 SQLite 的模式（`default` / `signaling` / `service-daemon`）都提供这两个页面；纯 `desk-server` 没有该数据库，也就没有这两个页面。

## 保留期配置

**用量 → 数据保留**页设置两类汇总各自保留的天数：

- **TURN 流量保留天数** 与 **AI Token 用量保留天数**，各自独立，取值范围 `[1, 10000]` 天，**默认 30 天**。
- 后台清理循环删除超过保留期的汇总行。便携版是**单机**运行且不计费，因此清理直接按龄删除——不存在需要保留的计费安全窗口。
- 配置是本地单行、按后写覆盖（last-writer-wins，无版本号）保存，在下一轮清理与查询时生效。
