# 用量统计与数据保留

便携版和信令服务器会将 **TURN 中继流量**按设备、按小时汇总到本机 signal SQLite 数据库，单机服务器不会据此计费。模型请求和 Token 用量使用独立的[模型调用指标](/zh/features/model-metrics)存储与页面。

## 用量页面与查询范围

**用量 → TURN 流量**页顶部提供**时间范围选择器**：

- **预设**：最近 24 小时 / 最近 7 天 / 最近 30 天，或选**自定义**起止时间。
- **实际范围**：后端会把请求范围收敛到配置的保留期与「现在」之内，并在图表下方回显实际查询到的范围。
- **按天聚合（UTC）**：跨度超过 **14 天**时自动按 **UTC 自然日**聚合以控制查询开销；日界固定以 UTC-0 为准，与本地时区无关。
- **与 TURN 是否在运行无关**：页面读取已落库汇总，TURN 未配置、启动失败或关闭时仍可查询保留期内流量。具有本机 signal 数据库的模式（`default` / `signaling` / `service-daemon`）提供本页，纯 `desk-server` 不提供。

## 保留期配置

**用量 → 数据保留**页独立设置 TURN 汇总与 AI 会话的保留期：

- **TURN 流量保留天数**范围 `[1, 10000]` 天，**默认 30 天**。模型调用统计的保留时间在**设置 → 模型调用统计设置**中单独管理。
- **AI 会话保留天数**同样为 `[1, 10000]` 天，**默认 30 天**，管理会话生命周期并遵循既有待处理工作保护，与不含内容的模型观测独立。延长保留期不能恢复已经删除的会话或统计。
- 后台清理循环删除超过保留期的汇总行。便携版是**单机**运行且不计费，因此清理直接按龄删除——不存在需要保留的计费安全窗口。
- 配置是本地单行、按后写覆盖（last-writer-wins，无版本号）保存，在下一轮清理与查询时生效。
