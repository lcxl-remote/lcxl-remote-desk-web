# 终端、文件与剪贴板

除了屏幕控制，LCXL Remote Desk 还通过专用 WebRTC 数据通道捆绑了日常实用功能。

::: info 通过访问码连接时
当你通过兑换[访问码](/zh/guide/access-codes)（设备码或支援码）连接、而非以设备 owner 身份连接时，下面的终端、文件与剪贴板能力受该码的能力上限、被控端全局访问设置与现场审批约束——并非自动可用。
:::

## 远程终端

内置的 [xterm.js](https://xtermjs.org/) 终端通过专用数据通道支持完整 shell 交互。无需离开浏览器会话即可进行命令行工作。

## 文件管理

直接从浏览器管理远端设备上的文件：

- **上传**文件到远端机器。
- **下载**文件回控制端。
- **删除**文件，并带**回收站**机制以便可恢复删除。

被控端拒绝的传输——安全设置里关闭了文件传输，或 owner 在弹窗中拒绝——会在传输条上直接显示为「被拒绝」，而不是停在 0%。若被控端中途停止响应，该传输会在 30 秒后中止，可重新发起。

上传到一个已存在的文件会覆盖它，且始终是一步到位。上传进行中，字节写入目标文件旁边的临时文件 `.<文件名>.<编号>.part`；直到整个文件收齐并落盘，临时文件才取代目标文件的名字，在此之前目标文件原封不动。因此上传被取消、磁盘写满或连接中断都不会有任何代价——原来那个文件仍然是当前的文件，临时文件会被清掉。两个传输同时上传到同一路径会互相覆盖结果，所以第二个会被拒绝而不是被接受。

### Windows 服务模式被控端上的映射网络驱动器

以 Windows 系统服务运行的被控端，是用提权账户在与桌面用户不同的登录会话中浏览文件的，而 Windows 把映射网络驱动器限定在登录会话内。因此用户在资源管理器里映射的盘符不会出现在驱动器列表中。改用 UNC 路径（`\\server\share`）访问这些位置，或把 `EnableLinkedConnections` 设为 `1` 并重启机器，让两个会话共享映射。

被控端自报为服务模式时，文件管理器会在驱动器列表页给出这一说明——它是**向被控端**询问的，所以经信令服务器或 manager 远程浏览时同样会出现，而不是只在浏览器与被控端是同一台机器时才有。

## 剪贴板同步

文本剪贴板的**双向**同步，让控制端与远端设备之间的复制/粘贴无缝衔接。

## 系统音频

远端音频播放被采集并同步到控制端（Opus 编码）。见[远程控制与串流](/zh/features/streaming#音频)。
