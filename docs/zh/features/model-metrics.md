# 模型调用指标

在 **用量统计 → 模型调用指标** 中查看。本页只向已登录的设备所有者开放，设备码访客无法访问。

本页帮助你查看模型调用是否成功、哪些工具参数容易出错，以及调用次数和耗时。**统计在一些极端场景下可能并不完整，数据仅供参考。** 统计出现故障不会影响模型答复、工具授权、执行或用量处理。

## 查看和筛选

先选择时间范围，再按模型、调用入口、用途、工具或错误类别筛选。一次最多查询 90 天。

- **总览**：调用次数、错误率、耗时和趋势。点击统计卡片可查看对应记录。
- **模型对比**：比较不同模型的调用情况。
- **工具入参 / 引用 / 纠错**：查看参数校验问题和模型收到反馈后的修改结果。
- **调用明细**：逐条查看调用结果、工具输入次数和 Token 用量。可只看错误或慢调用。
- **运行观测**：查看助手回合、上下文压缩和相关服务的运行情况。
- **未关联事实**：查看缺少原调用信息、暂时无法纳入统计的记录。该列表只按接收时间筛选。

**Token 用量**显示输入、输出及缓存用量，可单独选择时间范围。调用质量按调用开始时间统计，Token 用量按报告时间统计，因此两者的数量可能不同。

页面中的时间，包括查询范围、趋势、调用详情和统计更新时间，均按**当前设备的本地时区**显示，只展示日期和时间。切换界面语言不会改变时区。导出的时间保留带时区的标准格式，便于准确比较同一个时间点。

总览还可以比较两个时间段。比较时应同时看记录数量、模型配置和数据完整度；错误率下降不一定说明模型或工具改动产生了效果。

## 理解结果

| 指标 | 如何理解 |
|---|---|
| 模型调用次数 | 应用向模型发起的请求次数。同一次请求内部的重试另列为 HTTP 尝试。 |
| 请求失败率 | 已知失败次数占“已返回与已知失败调用”的比例。取消、未发出和结果未知的调用单独展示。 |
| 工具参数错误 | 模型生成的参数是否通过格式、字段、引用和执行前检查。用户拒绝授权不算参数错误。 |
| 纠错后的输入通过率 | 模型收到错误反馈后，下一次可确认关联的输入是否通过检查。通过不代表实际任务已完成。 |
| 执行验证率 | 已发出的操作中，有多少取得了已验证结果。已接受或结果未知的操作不会当作执行成功。 |
| P50 / P95 / P99 耗时 | 估算的耗时分布。例如 P95 表示约 95% 的记录耗时不超过该值。 |
| Token 用量 | 模型报告的用量。未报告的数值显示未知，不会补成零。 |

错误率旁会显示参与计算的次数。记录很少时，例如只有一次调用，不宜直接与大量调用的结果比较。没有可用于计算的记录时，不显示 `0%`。

模型或工具列表可能只展示部分项目。未列出的项目可通过准确的 ID 或工具名称筛选；剩余分组会合并到“其他”。参数字段排名也只基于当前保留的记录。

## 数据不完整时

统计默认开启，在后台更新。服务异常、进程退出、记录积压或存储空间不足时，部分记录可能未能保存。旧记录也可能因为保留时间或容量上限而被清理。

页面会显示采集状态、开始采集时间、等待处理的记录和已知缺口。**没有数据并不代表没有错误**；部分故障也可能无法准确统计丢失了多少记录。

只有开启本功能后采集的新记录可用。启用前的调用、旧累计值和日志不会导入或补算。缺少原调用信息的记录，在相关信息到齐后可能更新；页面不会因此重新调用模型或执行工具。

## 统计设置与保留

在 **设置 → 信令服务 → 模型调用统计设置** 中修改。也可以使用指标页顶部的设置按钮。

| 设置 | 默认值 | 可设置范围 |
|---|---|---|
| 调用明细保留 | 7 天 | 1–90 天 |
| 五分钟汇总保留 | 7 天 | 1–30 天 |
| 小时汇总保留 | 90 天 | 1–365 天 |
| 迟到结果可更新的时间 | 7 天 | 不超过明细和小时汇总的保留时间 |
| 明细 / 关联记录上限 | 各 10 万 | 关联记录上限不能小于明细上限 |
| 等待统计的记录上限 | 2 万 | 1,000–1,000,000 条 |
| 汇总记录上限 | 2.5 万 | 1,000–1,000,000 条 |
| 每个时间段的分组上限 | 256 | 16–1,024 组 |
| 统计存储上限 | 256 MiB | 16 MiB–16 GiB |

容量上限可能使记录在保留时间到期前被清理。缩短保留时间会清理旧记录，延长时间或调高容量不能恢复已删除的数据。实际磁盘占用还包含索引和数据库临时文件，可能高于统计存储上限。

其他管理员同时修改设置时，页面会要求加载最新设置并重新核对，避免覆盖他人的改动。TURN、会话和计费用量的保留时间仍在各自的数据保留设置中管理。

## 导出与隐私

总览、模型和工具标签页可导出当前筛选的统计结果。调用明细的 **导出当前页 CSV** 只导出当前页，不会自动下载后续页。

导出包含筛选条件、时间范围和数据完整度说明。详情和 CSV 不包含问题内容、模型回答、工具参数值、截图、命令、文件路径或密钥；明细导出还排除用户、设备、会话和内部关联标识。打开记录不会授予执行权限。

## 备份和故障处理

本机统计保存在独立的 `model-metrics.sqlite` 中。备份时使用 SQLite 一致备份，或先停止服务再复制文件；运行期间只复制主文件可能遗漏尚未写回的数据。

提供本机信令服务的便携、信令和系统服务模式支持本功能；纯桌面服务模式不提供本机统计。连接外部 Manager 时，平台统计仍在 Manager 中查看。

数据暂时不可用时，可先关闭页面的自动刷新，再检查数据库空间、权限和服务日志。修复后核对统计状态与最近更新时间。不要通过清空业务数据库处理单独的统计故障。备份恢复不能补出从未保存的记录，也不会重放工具或重新结算账单。
