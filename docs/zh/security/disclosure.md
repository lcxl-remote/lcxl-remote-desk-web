# 漏洞披露

我们认真对待 LCXL Remote Desk 的安全。远程桌面技术涉及对计算机系统的深度访问，因此负责任的披露至关重要。

## 报告漏洞

若你发现安全漏洞，请**私下报告**，而不要公开提 issue。当前的报告渠道与流程请参阅仓库中的 [`SECURITY.md`](https://github.com/lcxl/lcxl-remote-desk-web/blob/main/SECURITY.md)。

请包含：

- 漏洞描述及其影响。
- 复现步骤。
- 受影响的版本 / commit 及环境细节。

## 范围

本项目处于早期开发阶段。请将你的部署环境视为安全敏感：确保网络安全、限制可信用户访问，并将 API Key 保留在服务端（设计本身已强制这一点——见 [AI 安全模型](/zh/security/ai-security-model)）。

## 免责声明

远程桌面技术涉及对计算机系统的深度访问。作者不对使用本项目造成的任何损害负责。
