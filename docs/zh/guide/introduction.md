# 介绍

**LCXL Remote Desk** 是一款 AI 原生、开源且高性能的远程桌面。AI 与浏览器一样，都是系统正式支持的控制入口：内置诊断助手可以读取设备状态并提出命令建议，设备所有者逐条确认后才会执行；外部 AI 助手则只能通过只读 [MCP](https://modelcontextprotocol.io/) 服务获取信息。

后端使用 Rust 和 Actix Web，前端使用 React、Vite 与 Tailwind CSS。

## 为什么是 AI 原生？

AI 层是**安全优先、模型无关**的（兼容 OpenAI 与 Anthropic API）。其设计建立在几条不变量之上：

- **服务端是权限的唯一可信源**——控制端永远无法自报身份、范围或风险。
- **模型默认只给建议，不直接执行**——风险较高的操作必须经过服务端，并由用户明确确认。
- **数据在发送给模型前严格脱敏**——脱敏失败会立即中止请求。
- **每次调用都会留下审计记录**，但只保存元数据；API 密钥也只保存在服务端。

完整内容见 [AI 安全模型](/zh/security/ai-security-model)。

## 核心功能

- **AI 诊断**——使用自然语言提问；系统采集只读状态，在本地脱敏后交给模型分析。在设备所有者自己的设备上，诊断助手还可请求执行受支持的命令，但所有者查看并确认完整命令后才会真正执行。
- **只读 MCP 服务**——`--startup-mode mcp-stdio` 向本地 AI 助手暴露一个静态白名单的只读工具集，无执行或写入权限。
- **高性能串流**——基于 WebRTC，支持 AV1 / H.264 / VP8 / VP9 编码与 Opus 音频。
- **远程终端**——内置基于 xterm.js 的终端，支持完整的命令行交互。
- **文件管理**——上传、下载、删除，并带回收站机制。
- **剪贴板同步**——文本剪贴板双向同步。
- **远程白板**——在远端屏幕上绘制与批注（需 `tauri-app`）。
- **防窥屏**——远程操作期间锁定本地显示与输入（需 `tauri-app`）。
- **系统音频**——采集并同步远端音频播放。
- **多语言**——UI 与文档提供中英文。
